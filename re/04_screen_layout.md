# 04. 화면 레이아웃 (보드 · 음영 상자(DSB) · 상태 표시줄 · 점수판)

근거: `Mighty.exe` 디컴파일(주소는 함수 시작 주소), objdump 확인, 리소스 파싱, 그리고 **실제 XP 스크린샷**
`screenshots/original_election.webp` (1066x927, 5마 선거 장면)으로 대조했다.
목업은 `mockups/`에 있다(생성 스크립트는 세션 스크래치패드에 둠, 원본 카드 비트맵은 로컬 비교용으로만 사용).

> 웹 버전 우선순위: ① 내 손패는 아래쪽 ② 인원별 좌석 배치 ③ 트릭 카드 위치 ④ DSB/상태줄로 안내 ⑤ 주공 버리기·프랜드 지정 흐름.
> 픽셀 단위로 맞출 필요는 없고, 아래 비율 공식을 그대로 쓰면 원작 느낌이 난다.

## 2. 카드 크기 (창 크기에 따라 확대·축소) — `FUN_00407030`

원본 카드 71x96. `ZoomCard`(기본 1)일 때 클라이언트 W,H로 배율 s(천분율)를 정한다.

```
minW = 2*96 + 5*71/2 = 369   maxW = 2*96 + 7*71/2 = 440
minH = 9*96/2       = 432   maxH = 11*96/2      = 528
sx = W<minW ? W*1000/minW : W>maxW ? W*1000/maxW : 1000   (sy도 같은 방식)
if sx>=1000 && sy>=1000:  s = (sx>1000 && sy>1000) ? max(1000, round_to_500(min(sx,sy))) : 1000
else:                     s = min(sx,sy)        // 축소는 연속, 확대는 0.5배 단위(1.0/1.5/2.0...)
cw = 71*s/1000, ch = 96*s/1000
```
스크린샷 검증: 클라이언트 ≈1058x850 → s=1500 → **106x144** (측정 105x142).
보드 글꼴 = "돋움", 굵기 600, 높이 `f = ch*14/96` px (1.5배일 때 21px). 크기 변형: f, 1.5f, 2.5f와 고정 14/21/35px (`FUN_00407200`).

## 3. 좌석 배치와 카드 영역 — `FUN_004073c0` (핵심)

`rect(nPlayers, mode, seat, cw, ch, index, count)`. 화면 위치 = 내 자리 기준 상대 위치(`FUN_00406be0`: 반시계 규칙이면 `n-seat`).
위치 플래그 표 `DAT_00437ae4[n][pos]`:

| 인원 | pos0 (나) | pos1 | pos2 | pos3 | pos4 | pos5 |
|---|---|---|---|---|---|---|
| 3 | 아래 가운데 | 왼쪽·위쪽 중간 | 오른쪽·위쪽 중간 | | | |
| 4 | 아래 가운데 | 왼쪽·가운데 | 위 가운데 | 오른쪽·가운데 | | |
| 5 | 아래 가운데 | 왼쪽·아래쪽 중간 | 위·왼쪽 반 | 위·오른쪽 반 | 오른쪽·아래쪽 중간 | |
| 6 | **아래·오른쪽 반** | 아래·왼쪽 반 | 왼쪽·가운데 | 위·왼쪽 반 | 위·오른쪽 반 | 오른쪽·가운데 |

(플래그 비트: x = 1 왼쪽 / 2 왼쪽 반 / 4 가운데 / 8 오른쪽 반 / 0x10 오른쪽, y = 0x20 위 / 0x40 위쪽 중간 / 0x80 가운데 / 0x100 아래쪽 중간 / 0x200 아래.)
왼쪽·오른쪽 좌석(1/0x10)은 **세로**로 쌓고, 나머지는 가로로 편다. 6마는 내 손패가 오른쪽 아래, 다른 한 명이 왼쪽 아래에 나란히 놓인다.

### mode 2 — 손패 영역 (W,H=클라이언트, cx,cy=중심, base = ch+2cw)
- 가로 좌석: 폭 `3.5cw + max(0,(W-2·base)/2)`, 높이 ch.
  x: 가운데 정렬 / "왼쪽 반"은 오른쪽 끝 = `cx - cx/20` / "오른쪽 반"은 왼쪽 끝 = `cx + (W-cx)/20`.
  y: 위 좌석 top=0, 아래 좌석 bottom=H (H < 5.5ch면 중앙 기준 ±7ch/4로 당김).
- 세로 좌석: 폭 cw, 높이 `H/2 + ch/4`(좁으면 3ch). x: 왼쪽 0 / 오른쪽 W-cw. y: 중심을 `cy ± h/7`(위쪽/아래쪽 중간) 또는 cy.
- 카드 배치: 영역보다 카드가 많으면 **겹침** `x = left + (areaW-cw)*i/(count-1)`, 적으면 가운데 정렬로 붙여 놓음. 아래·오른쪽 좌석은 왼→오/위→아래 순서, 위·왼쪽 좌석은 역순.
- 스크린샷 대조: 손패 폭 544 = 3.5·106 + (1058-2·356)/2 ✓, 좌우 스택 높이 457 = 425+36 ✓.

### mode 1 — 득점 카드(딴 점수 카드) 영역
- 가로: 폭 `7cw/4 + max(0,(W-2·base)/3)`, 위치 기준은 `cx ± cx/6`. y: 위 좌석 top = **ch/2**, 아래 좌석 bottom = **H - ch/2** → 손패보다 먼저 그려서 **손패 뒤에서 반 장(ch/2) 삐져나온다**.
- 세로: 높이 `H/2 - 3ch/4`, x = cw/2 (왼쪽) / W-cw/2-cw (오른쪽) → 손패 옆으로 반 장 삐져나옴.
- 앞/뒷면: 규칙 '득점한 카드는 뒤집어 놓기'(rule+0x37)면 뒷면 (`FUN_00404d10`).

### mode 0 — 트릭(바닥에 낸 카드) 영역
중앙 박스 `aw = 3cw - cw/5`, `ah = 2ch + 8`, 클라이언트 중앙 정렬. 좌석별 카드 위치(같은 플래그 사용):
x: 왼쪽 `l+2` / 왼쪽 반 `l+(cx-l)/3` / 가운데 `cx-cw/2` / 오른쪽 반 `r-(r-cx)/3-cw` / 오른쪽 `r-2-cw`;
y: 위·위쪽 중간 `t+2` / 가운데 `cy-ch/2` / 아래쪽 중간 `cy+ch/7-ch/2` / 아래 `b-2-ch`.
→ 5마는 오각형, 4마는 십자, 3마는 역삼각형(내 카드가 아래). 그리는 순서는 선(+0x10c)부터 (`FUN_00404680`).

### mode 3 — 화면 밖 위치
각 좌석 방향으로 클라이언트 바깥 5px. 카드를 나눠 주거나 트릭을 가져갈 때 애니메이션 시작/끝점.

### 손패 상호작용 표시 (`FUN_004043e0`)
- 선택된 카드(주공 버리기, 상태 2): **ch/5 위로**.
- 마우스 올린 카드(+0xf4): **ch/20 위로**.
- 내 손패만 앞면. 다른 사람 손패는 뒷면(기본 bitmap 772). 예외: 특정 좌석(+0x10c)이나 사람 플레이어가 없는 경우 등 플래그에 따라 앞면.
- 카드 도움말(CardHelp): 마이티/조커콜 카드 위에 빨간 글씨로 이름을 씀 (`FUN_00401b70`).
- 카드 그림 = 비트맵 54장을 한 줄 스트립으로 로드 후 `StretchBlt` (`FUN_004018b0`).

### 이름표 (`FUN_00404840`, `FUN_00406c30`)
돋움 600, 높이 f. 검은 1px 외곽선(상하좌우 4회) + 본색(여당 시안/야당 흰색).
**현재 차례인 플레이어(+0x110)는 이름 둘레에 사각형**(검은 그림자 +1px, 본색 선).
위치: 가운데 좌석 → 손패 오른쪽 끝 옆(아래 좌석은 하단 정렬) / 위쪽 반 좌석 → 손패 아래, 득점 영역 바깥쪽 끝에 맞춤(왼쪽 좌석은 오른쪽 정렬) / 좌우 좌석 → 득점 영역 아래, 손패의 안쪽 옆. 스크린샷과 일치.

### 가운데 덱/바닥패 (`FUN_00404b10`)
게임 중(상태≠3) 중앙에 뒷면 더미. 그릴 장수 = n<3 ? n : n<10 ? 2n/3 : (n-9)·cw/520+6, 한 장마다 2px씩 위로(입체감).
섞기 애니메이션은 중앙 2cw x 1.5ch 영역, 상태줄 "카드를 섞는 중입니다..." + 진행률 (`FUN_00405c90`).

## 4. DSB (음영 상자) — 보드 위에 그리는 반투명 대화 상자

모든 안내/입력은 **모달 대화상자가 아니라 보드 위 DSB**로 한다(시작 메뉴, 접속 주소 입력, 대기실, 선거, 버리기, 프랜드 지정, 결과).
- 기반 클래스: 생성 `FUN_004175b0`, 위치/크기 `FUN_00417980(x,y,w,h,timeout)`, 사각형 `FUN_00418370`, 항목 추가 `FUN_00417de0`, 그리기 `FUN_004186e0`.
- **단위 u**: 보드 글꼴 높이 f(1.5배일 때 21px). 단, 선거·버리기·프랜드 상자는 `FUN_00417b70`로 "작은 상자" 플래그를 켜서 **u=14 고정**, 글꼴도 고정 크기.
- 사각형: 클라이언트 중심 기준 `left = cx - w·u/2 + gx·f - 4`, `size = (w·u+4, h·u+4)` (gx,gy는 f 격자 오프셋).
- 그리기: 바탕을 ShadeMode로 어둡게(기본 50%, 스크린샷 RGB(0,128,0)→(1,66,1) ✓) → 테두리(바깥 위·왼 #808080, 바깥 아래·오른 #404040, 안쪽 위·왼 흰색, 안쪽 아래·오른 검정) → timeout<0(닫힐 때까지 유지)이면 **오른쪽 위 흰색 X**(12x12, 2px).
- 항목: 텍스트 또는 아이콘+텍스트, 위치는 상자 안 비율로 저장. 마우스를 올리면 다른 색/스타일로 바뀌는 버튼처럼 동작.
  스타일 비트: &3 글꼴 크기, 4 = 검은 그림자(+1,+1), 8 = 색의 60% 밝기로 외곽선(굵게 보임), 0x10 = 아이콘에 입체 테두리, 0x20 = 글자 뒤 검정 바탕. 기본 텍스트는 흰색+그림자(0x14).

### 진행 흐름 (사람 플레이어)
1. **딜**: 중앙 더미 + 섞기 애니메이션, 상태줄 "카드를 섞는 중입니다..."와 진행률.
2. **선거**: 중앙에 "초대 선거" 알림(X). 다른 사람이 공약을 내면 그 사람 근처에 말풍선. 상태줄 "~ 님의 공약 결정 중", 해당 이름에 사각형. 내 차례가 되면 손패 위에 선거 DSB가 뜬다(모달 아님).
3. **당선 발표**: 중앙 알림 "-- 선거 결과 발표 --"/"당선자가 확정되었습니다 !!"와 풍자 문구("당선자는 나머지 카드를 받고...").
4. **주공 재정비**: 바닥패 3장이 손패에 합쳐져 13장. 18x17 DSB가 뜨고, **손패에서 카드를 클릭하면 ch/5 올라감**. 3장을 고른 뒤 필요하면 기루다/목표를 바꾸고 "확정". 3장 전에 확정하면 "먼저, 버릴 카드 세 장을 선택하세요". 상태줄 "~ 님이 당을 재정비하고 있습니다".
5. **프랜드 지정**: 프랜드 DSB에서 텍스트 버튼이나 무늬+카드 띠로 카드를 고르면 **오른쪽 아래 큰 카드**가 바뀐다. 큰 카드를 클릭하면 확정. 잘못 고르면 "프랜드로 부를수 없는 카드입니다"/"이미 가지고 있거나 버린 카드입니다".
6. **트릭**: 상태줄 "~ 님 차례입니다". 낸 카드는 좌석 방향 중앙 박스에 놓이고, 조커콜·기루다컴 같은 선언은 짧은 알림 DSB로 표시. 턴이 끝나면 "~ 님이 이번 턴을 이겼습니다" 뒤 점수 카드가 이긴 사람의 득점 영역으로 이동.
7. **결과**: 25x25 결과 DSB와 점수판 창 갱신.

## 9. 불확실한 부분

- 6마: 탈락 뒤 화면 배치를 5마 표로 바꾸는지(n=CState+0xa8) 확인하지 못했다.

## 10. 웹 버전에 옮길 때
- 위 공식을 CSS 변수(cw, ch, W, H)로 옮기면 반응형이 된다. 모바일 세로 화면에서는 H < 5.5ch 분기(좌우 좌석을 중앙 쪽으로 당김)가 필요하다.
- 원작 카드 그림(Windows 카드 덱)은 쓰지 않는다. 71:96 비율과 겹침 규칙만 따른다.
- DSB = "보드 위 반투명 패널 + 노란 제목 + 텍스트 버튼(hover 시안)" 디자인 패턴으로 일반화하면 된다. 모달 없이 보드 위에서 모두 진행한다.
