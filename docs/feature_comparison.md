# 원작(마이티 네트워크 3.2)과 웹 버전 기능 비교

작성: 2026-10-18 (커밋 `11351b5` 기준). 근거: 원작 README·실행 파일 분석(`re/01~04`), 원작 설정 항목(레지스트리 키·옵션 화면), 웹 버전 스펙(`docs/use_cases.md`, `docs/server_spec.md`)과 코드.

분류
- **구현함**: 원작 기능을 웹 버전에 옮김 (바꾼 점은 따로 적음)
- **빠진 것**: 원작에 있고 웹에서 할 수 있지만 아직 안 만듦
- **일부러 뺀 것**: 결정에 따라 넣지 않음 (이유 포함)
- **구현할 수 없었던 것**: 기술·자료·권리 문제로 그대로 옮길 수 없었음
- **새로 생긴 것**: 원작에 없던 웹 버전 기능

## 1. 구현함

| 원작 기능 | 웹 버전 | 비고 |
|---|---|---|
| 마이티 규칙 전부 (카드, 공약·선거, 딜 미스, 6마 탈락, 바닥패·버리기, 프렌드 4종, 트릭 승자, 마이티·조커·조커콜, 정산 5방식·배수·분배·파산) | 엔진 (`packages/engine`) | 원작 버그 8건은 고친 동작으로 (`packages/engine/README.md`) |
| 3마·4마·5마·6마 | 지원 | 자리 배치도 원작 참고 |
| 30여 개 세부 규칙 옵션 | 엔진에 모든 옵션 구현 | 화면에서 고르는 건 프리셋만 (→ 빠진 것) |
| 미리 정의된 규칙 12종 | 프리셋 12종 + 특징 설명 | 원작 체감에 맞춰 일부 옵션 보정, 표준 5마 첫 공약 포기 불가 (사용자 결정) |
| 네트워크 여러 명 플레이 | WebSocket 서버 + 브라우저 | 방식은 완전히 다름 (→ 일부러 뺀 것) |
| 부족한 인원은 컴퓨터가 채움 | 빈자리는 봇이 채움 | 필수 요구사항 |
| AI 플레이어 | smart 봇 (기본), simple 봇 | 원작 AI 는 그대로 못 옮김 (→ 구현할 수 없었던 것) |
| 봇 기본 이름 | 아무개, 대중, 영삼, 태우, 두환, 정희 | 원작 기본 이름 표 그대로 |
| 게임판 배치 (가장자리 좌석, 아래 내 패, 트릭 카드 위치) | 원작 배치 참고 | 3·4·5·6마, 세로 화면 배치 추가 |
| 반투명 상자(DSB)로 공약·안내 | 판 위 반투명 상자 | 공약 상자, 주공 정리, 정산, 조커·조커콜 선택 |
| 공약: 무늬 아이콘·△▽·포기/출마/딜미스 | 같은 방식 | 기루다 추천·선택 유지 추가 |
| 주공 정리: 패에서 버릴 카드 올리기, 프렌드 빠른 선택(마이티/조커/기루다A/K/초구/노프) | 같은 방식 | 기루다 바꾸면 공약 자동 올림 |
| 상태 표시줄 (기루다·공약·프렌드·메시지) | 같은 구성 | |
| 전적 창 (이름·지지율) | 전적 창 (이름·점수·지지율) | 판별 기록은 없음 (→ 빠진 것) |
| 채팅 | 채팅 창 + 시스템 메시지 | |
| 부드러운 카드 이동 | 낸 카드·트릭 가져가기·내 패 재배치·바닥패 받기 애니메이션 | 속도 조절은 없음 |
| 소리 (원작 WAV 18개) | 효과음 (Web Audio 합성) + 켬/끔 | 원작 소리 파일은 안 씀 |
| 조커 리드 무늬 선언 | '기루다 컴' / '○○ 컴' | |
| 6마 탈락 지목 | 카드 지목 상자 | 브라우저 직접 시험은 못함 (자동 테스트만) |
| 대기실 (참가자, 방장, 내보내기, 시작) | 대기실 (큰 방 이름, 자리 카드, 봇 추가/빼기, 내보내기, 규칙·제한 시간) | |

## 2. 빠진 것 (할 수 있지만 아직 안 만듦)

| 원작 기능 | 상태 | 비고 |
|---|---|---|
| 세부 규칙 직접 편집 (옵션 대화상자 6쪽) | 없음 | 엔진은 모든 옵션 지원. 방장 편집 화면만 필요 |
| 규칙 문자열(14글자) 보기·붙여넣기로 공유 | 없음 | 엔진에 인코드/디코드 있음 |
| 판별 기록·점수 변화·분석 보기 (통산전적, 전적보기, 분석보기, 점수변화, 팀공헌도, 점유율, 실점/도움/득점) | 없음 | 방 안의 누적 점수만 보임 |
| 은어 표시 옵션 (곱트, 기아, 쪼카 등) | 없음 | 엔진에 은어 이름 함수 있음 |
| 손패 정렬 옵션 (기루다 왼쪽/오른쪽, 에이스 위치, 정렬 안 함) | 고정 정렬만 | |
| 카드 확대 보기 (ZoomCard) | 창 크기에 맞춘 자동 크기만 | |
| 카드 도움말 (CardTip: 카드 이름과 그보다 높은 카드) | 마우스 올리면 이름만 (title) | |
| 카드 섞기·나눠주기 애니메이션 (ShowDealing) | 없음 | |
| 속도 설정 (카드 속도·부드러움·대기 시간) | 고정값 | 서버 봇 지연 0.7초, 트릭 1.5초 |
| 배경 색·그림, 카드 뒷면 선택, 여당·야당 이름 색 | 고정 | 원작 기본(초록, 여당 하늘색)과 같음 |
| 채팅 말풍선(다른 사람 채팅을 판 위에 잠시 표시) | 채팅 창만 | |
| 도움말 (게임 방법, 규칙 설명) | 없음 | 원작 도움말은 일부만 해독됨 |
| AI 종류·옵션을 자리별로 고르기 | 모든 봇이 smart | simple 은 대결 실험용 |
| **방 비밀번호** (유스케이스 UC-A3 에 '선택'으로 있음) | 없음 | 요구사항에 있으나 미구현 |

## 3. 일부러 뺀 것

| 원작 기능 | 이유 |
|---|---|
| 원작 TCP 프로토콜 (방장 PC 가 서버, 락스텝 복제) | 모든 클라이언트에 덱 전체를 보내 남의 패가 노출됨. 서버가 판정하고 자기 패만 보내는 구조로 바꿈 |
| 원작 클라이언트와의 상호 접속 | 위와 같은 이유로 호환하지 않음 |
| BSW AI (기본 AI) | 남의 패와 바닥패를 훔쳐보는 방식 |
| AI DLL 플러그인 구조 (`MaiGetPlay` 등) | Windows DLL 이라 웹에서 쓸 수 없음. 봇은 서버 코드로 |
| 원작 카드 그림·카드 뒷면·아이콘 | Windows 카드 게임 그림으로 보여 저작권 문제. 고전 스타일로 새로 그림 |
| 보스키 (PAUSE 로 창 숨기기) | 브라우저에서는 의미 없음 (탭 전환으로 대신) |
| 회원가입·로그인, 영구 전적 저장 | 소규모 지인용, 닉네임만으로 입장하기로 결정 |
| Windows 레지스트리 설정·창 위치 기억, 느린 컴퓨터 옵션, 사용자 이름(GetUserName) | 웹 환경에 맞지 않음 |
| Mighty.Net 서버 주소 설정 | 원작의 계획 기능. 웹 버전은 서버 주소가 곧 접속 주소 |
| 원작 버그 동작 8건 | 고친 동작으로 구현 (엔진 README) |
| 판 끝 [그만]이면 게임 전체 종료 | 그 사람만 빠지고 봇이 이어받게 바꿈 |

## 4. 구현할 수 없었던 것

| 대상 | 이유 | 대안 |
|---|---|---|
| 원작을 실제로 실행해서 비교 | Mac 에서 Wine 패키지가 막혀 있음 (Gatekeeper) | 디컴파일 코드 + 원작 캡처 1장으로 배치·동작 재구성 |
| 원작 AI(Xiao) 그대로 옮기기 | BSW 는 치트, Xiao 도 바닥패를 봄. 가중치·벌점표 의미 일부 미해석 | 공개 정보만 쓰는 smart 봇을 새로 만들고 봇 대결로 조정 |
| 원작과 실제 판 결과 대조 | 원작 실행 불가 | 엔진 단위 테스트·시뮬레이션으로 규칙 일관성만 검증 |
| 원작 도움말 전문 | Hall 압축 일부 미해독 (단어가 빠짐) | 필요한 규칙은 코드에서 확인 |
| 원작 효과음 | 원작 WAV 출처 불명 (저작권 불확실) | Web Audio 로 새로 합성 |
| 일부 규칙 필드 의미 (S[0x78], 0xd4~0xdc, 0x36 프렌드 득점 즉시 공개의 실제 사용처) | 코드에서 사용처를 못 찾음 | 엔진에는 옵션 값만 보관, 공개 시점은 '프렌드 카드를 낼 때' |

## 5. 새로 생긴 것 (원작에 없음)

- 로비 방 목록(방 카드), 방 링크, 닉네임 입장, 새 창에서 [계속]/[다른 닉네임] 선택, 다른 창에 밀려남 처리
- 관전과 봇 자리 넘겨받기, 연결이 끊기면 봇이 대신 치고 재접속하면 되찾기
- 방장이 정하는 차례 제한 시간(없음/30/60/90/120초), 시간 초과면 봇이 대신 결정, 일시정지
- 판 끝 [계속]/[그만], 방장 넘기기, 사람이 다 나가면 방 닫기
- 프리셋 특징 설명(표준 규칙과 다른 점), 기루다 추천, 포기 불가 첫 공약은 '기노' 기본 선택
- 공약 상자(기루다 크게, 프렌드 조건 → 누구), 딴 점수카드 펼쳐 보기, 새 정산 화면(승패·점수 막대·팀별)
- 세로 화면(휴대폰) 배치, 창 크기에 맞춘 카드 크기
- 봇 대결 실행기(`scripts/bench.ts`), 개발용 3인 시험 화면(`dev.html`)
