# 웹 마이티 — 유스케이스 (초안)

목표: 아주 단순한 서버 1대 + 브라우저 클라이언트 여럿이 접속해서 마이티를 함께 친다.
원작(마이티 네트워크 3.2)의 규칙·흐름을 따르되, 서버가 판정을 맡고 각자 자기 패만 본다.

> ❓ 표시는 결정이 필요한 항목.

## 액터

| 액터 | 설명 |
|---|---|
| 플레이어 | 브라우저로 접속해 게임에 참여하는 사람 |
| 방장 | 방을 만든 플레이어. 규칙·자리·시작을 정함 |
| 관전자 | 자리 없이 구경하는 사람. 원하면 봇 자리를 넘겨받아 플레이어가 된다 |
| AI | 빈 자리를 채우는 컴퓨터 플레이어 (Xiao 방식 포팅) |
| 서버 | 방 관리, 카드 섞기·분배, 규칙 판정, 점수 계산 |

## A. 접속과 방

**UC-A1 닉네임으로 입장** (확정)
- 사이트에 들어가 닉네임만 입력하고 입장한다. 회원가입·로그인 없음.
- 같은 브라우저로 다시 오면 저장된 토큰으로 같은 사람으로 인식한다 (server_spec §3).

**UC-A2 방 목록 보기**
- 열린 방들의 이름, 인원(예: 3/5), 규칙 프리셋, 진행 상태(대기/게임 중)를 본다.
- (확정) 로비 방 목록 방식. 방 링크 공유도 함께 지원.

**UC-A3 방 만들기**
- 방 이름, 규칙 프리셋(표준 5마 등 12종), 비밀번호(선택)를 정해 방을 만든다. 만든 사람이 방장.
- 방 링크(예: `/room/abc123`)를 친구에게 공유할 수 있다.
- 프리셋을 고르면 그 특징을 함께 보여준다 (확정):
  - 핵심 요약: 인원, 기본 공약, 프렌드 유무, 점수법, 런 보상, 마이티·조커콜 카드
  - 지역 규칙이면 같은 인원의 표준 규칙과 다른 점 목록 (예: 신촌 5마 → "공약을 25까지 부를 수 있음", "주공이 버린 카드의 점수는 야당 몫")
  - 문구는 규칙 값에서 자동으로 만든다 (`@mighty/engine`의 `describePreset`)

**UC-A4 방 들어가기**
- 목록 또는 링크로 방에 들어가 빈 자리에 앉는다.
- 자리가 다 찼거나 게임 중이면 관전자로 입장한다.

**UC-A4a 관전하다가 자리 넘겨받기** (확정)
- 관전자는 공개 정보만 보고 채팅할 수 있다.
- 봇 자리를 골라 [이 자리 넘겨받기]를 누르면 다음 결정부터 직접 플레이한다.

**UC-A5 대기실**
- 앉은 사람 목록(닉네임, 전적), 적용 규칙, 채팅을 본다.
- 방장은: 규칙 변경(프리셋 + 세부 옵션), 차례 제한 시간 설정, 빈 자리를 AI로 채우기/비우기, 플레이어 내보내기, 게임 시작.
- **(필수) 시작 시 빈자리는 모두 봇으로 채운다.** 사람 1명이어도 시작 가능 (server_spec §5).

**UC-A6 채팅**
- 대기실과 게임 중 모두 채팅 가능. 입장/퇴장/추방 같은 시스템 메시지도 채팅창에 표시.

## B. 한 판 진행 (서버가 순서를 진행하고, 차례가 된 사람에게만 입력을 요청)

**UC-B1 카드 받기**
- 서버가 섞어서 나눠 준다. 각자 자기 패만 보인다 (5마 10장씩, 바닥 3장).

**UC-B2 출마(공약)**
- 차례대로: 기루다 무늬 + 목표 점수를 부르거나, 포기하거나, 딜미스를 선언한다.
- 화면은 지금 부를 수 있는 값만 고를 수 있게 한다 (현재 최고 공약보다 높게, 최소/최대 점수 등).
- 딜미스는 패가 조건에 맞을 때만 버튼이 활성화된다.
- 전원 포기 또는 딜미스 → 다시 섞어서 나눔.

**UC-B3 (6마만) 한 명 탈락시키기**
- 주공이 카드 한 장을 지목 → 그 카드를 가진 사람이 이번 판에서 빠진다.

**UC-B4 주공의 패 정리**
- 주공이 바닥 3장을 받아 13장 중 3장을 버린다.
- 기루다/목표 점수를 바꿀 수 있다 (규칙에 따라 +1 또는 +2 올려야 함).
- 프렌드 지정: 카드 지정 / 특정 플레이어 / 초구 프렌드 / 노프렌드.
- 다른 사람들에게는 최종 공약과 프렌드 조건이 공개된다 (버린 카드는 비공개).

**UC-B5 카드 내기 (10트릭)**
- 내 차례에 낼 수 있는 카드만 활성화된다.
- 선이 조커를 낼 때: 무늬 선언. 선이 조커콜 카드를 낼 때: 조커콜 할지 선택.
- 트릭마다 누가 이겼는지, 딴 점수카드가 보인다. 프렌드 카드가 나오면 프렌드 공개.
- 차례 제한 시간은 방장이 정한다. 시간이 지나면 봇 로직이 대신 결정한다 (확정).

**UC-B6 정산**
- 판이 끝나면 여당/야당 점수, 계산식, 각자 점수 변동을 보여준다.
- 원작 정책대로 각자 [계속]/[그만]을 고른다. 모두 [계속]이면 다음 판을 시작하고, 주공(또는 규칙에 따라 프렌드)이 선이 된다.
- [그만]을 고른 사람만 자리에서 일어나고 그 자리는 봇이 맡는다 (확정).

**UC-B7 점수판**
- 지금까지 판별 결과와 누적 점수를 본다.

## C. 예외 상황

**UC-C1 연결이 끊김** (필수)
- 끊긴 자리는 즉시 봇이 대신 친다. 같은 사람이 다시 접속하면 자리를 되찾는다.
  (원작은 끊기면 판 전체가 끝남 → 개선)

**UC-C2 게임 중 나가기**
- 나가면 그 자리는 AI로 바뀐다. 사람이 모두 나가면 방이 닫힌다.

**UC-C3 방장이 나감**
- 남은 사람 중 한 명에게 방장이 넘어간다.

**UC-C4 추방**
- 방장이 대기실에서 플레이어를 내보낸다. ❓ 게임 중에도 가능하게 할지

## D. 1차 범위에서 뺄 것 (제안)

- 회원가입/로그인, 전적 저장 (확정: 저장하지 않음. 점수는 방이 살아 있는 동안만 유지)
- 원작의 배경 그림·카드 뒷면 바꾸기, 보스키, 카드 확대 등 부가 기능
- BSW AI(남의 패를 훔쳐보는 방식) — Xiao 방식만 포팅
- 모바일 전용 레이아웃 ❓

## 열린 질문 정리

1. ~~로그인 없이 닉네임만으로 충분한가?~~ → 닉네임만 (확정)
2. ~~방 목록이 필요한가?~~ → 로비 방 목록 (확정)
3. ~~관전 기능~~ → 넣는다. 관전하다가 봇 자리를 넘겨받을 수 있다 (확정)
4. ~~차례 제한 시간~~ → 방장이 정한다 (확정)
5. ~~다음 판 시작~~ → 원작 정책: 각자 계속/그만 (확정)
6. 모바일(세로 화면) 지원이 1차에 필요한가?
7. ~~예상 동시 접속 규모~~ → 아는 사람끼리 소규모 (확정)
